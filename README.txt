Запуск:  dotnet run   (нужен .NET 8 SDK)  ->  http://localhost:5000
База данных: data/quizzes.json (создаётся сам; внутри квизы и игры «Своя игра»)
Старый data/quizzes.json (только квизы) подхватывается автоматически.
Порт/адрес: переменная ASPNETCORE_URLS, например http://0.0.0.0:80

Бесплатный доступ из интернета (Cloudflare Tunnel):
1) Установите cloudflared (winget install Cloudflare.cloudflared)
2) Запустите start.bat (Linux/Mac: start.sh) - в окне появится ссылка https://....trycloudflare.com
3) Все данные остаются у вас в data/quizzes.json. Ссылка меняется при каждом запуске (постоянная - через аккаунт Cloudflare и свой домен).
Античит: порядок вопросов, время и очки считает сервер; правильный ответ показывается только после ответа; в рейтинге один результат на имя (лучший).

Аккаунты: регистрация и вход (имя + пароль от 8 символов, буквы и цифры). Пароли хранятся только как PBKDF2-хеш в data/quizzes.json, вход сохраняется 14 дней и переживает перезапуск. Не удаляйте этот файл и делайте его копии.
Играть и открывать квизы можно без аккаунта. Вход нужен только чтобы создавать квизы и игры (и удалять их с любого устройства).

Безопасность: в «Своей игре» вопрос приходит только при открытии ячейки, ответ только после открытия вопроса. Квиз копируется в игровую сессию при старте. Токены живут 14 дней, максимум 5 устройств. Пароль от 8 символов (буквы и цифры). Лимиты: 5 регистраций в час и 30 активных игр на IP. Допуск времени ответа: переменная LARP_GRACE_MS (по умолчанию 800 мс).
Файлы: data/app.log (события и ошибки, без паролей), data/backups (копия базы каждые 6 часов, последние 20).

API: список всех адресов на странице /api.html. Фото: загружаются как JPEG в data/img (вход нужен). Готовые квизы (общие знания, география, история, наука, тест на логику) добавляются один раз при первом запуске.

Новое: красная кнопка в «Своей игре» (вкл/выкл, у каждой команды своя, клавиши 1-8), случайный тест и случайная игра (/api/quizzes/random, /api/boards/random), больше готовых квизов и игр (добавляются один раз). Страница /api.html осталась, но из меню убрана.

Админ-панель: войдите админом (см. ниже), в профиле кнопка «Админ-панель».

ЗАЩИТА (по замечаниям)
- Лимиты: общий 240 API-запросов/мин на IP; отдельные: вход/регистрация/пароль 10/мин, фото 10/мин, игра 120/мин, создание квизов/игр/жалоб 20/мин. Не больше 8 игр с одного IP и 3 на аккаунт; брошенные сессии удаляются через 30 минут.
- Cloudflare: заголовку CF-Connecting-IP сервер верит только при LARP_BEHIND_CF=1 и только если запрос пришёл с localhost (туда приходит cloudflared) или из LARP_PROXY_IPS (через запятую). start.bat/start.sh ставят LARP_BEHIND_CF=1. Если сервер открыт напрямую в интернет, НЕ включайте эту переменную.
- Фото: сервер определяет реальный формат (только JPEG), проверяет размер 16-4000 px, уменьшает до 1280 px, убирает метаданные, пересохраняет (форк FreeDotnetImageSharp 2.1.15: у SixLabors.ImageSharp 3.x нет исправлений известных уязвимостей, они закрыты только в платной 4.x). Не больше 100 фото на аккаунт. Фото, которых нет ни в одном квизе, удаляются автоматически (раз в 10 минут, через час после загрузки).
- Очистка: устаревшие записи ограничителей входа/регистрации, токены, сессии и сессии ведущего чистятся каждые 10 минут.
- Вход: токен лежит в HttpOnly + SameSite=Strict cookie (Secure на https), JavaScript его не видит, в localStorage его больше нет.
- Публичный API не отдаёт UserId: в таблице лидеров только name, points, correct, at.
- Роль admin хранится у пользователя; админа можно выдать/забрать в панели, блокировать пользователей можно, админов - нельзя.

ТЕСТЫ
LarpQuizov.Tests (xUnit) проверяют игровую логику из Logic.cs: очки и таймер, подсказку 50/50, режим выживания, нормализацию имён, проверку адресов фото. Запуск: dotnet test (из папки решения, нужен интернет для NuGet).

БЕЗОПАСНОСТЬ
1) Админ по имени (было: имена ald и elaman получали admin при регистрации, любой мог занять имя). Теперь регистрация ВСЕГДА создаёт обычного пользователя. 4) Библиотека изображений: FreeDotnetImageSharp 2.1.15 оставлена намеренно (см. раздел v7): у SixLabors.ImageSharp 3.x нет исправлений известных уязвимостей, они закрыты только в платной 4.x.
