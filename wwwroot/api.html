LarpQuizov API

Формат: JSON. «Вход» значит: браузер отправляет HttpOnly-cookie lq_token (ставится после /api/login или /api/register), а скрипты могут передавать заголовок Authorization: Bearer <token> (token есть в ответе логина). Токен действует 14 дней. Коды: 200 ок, 201 создано, 400 неверные данные, 401 нужен вход, 403 не автор, 404 не найдено, 409 имя занято, 410 сессия истекла, 429 слишком много запросов.

Лимиты (на IP): всего 240 API-запросов в минуту; вход, регистрация и смена пароля 10/мин; загрузка фото 10/мин; игровые запросы 120/мин; создание квизов, игр и жалоб 20/мин. Одновременно не больше 8 игр с IP и 3 на аккаунт. Ответ 429 при превышении.

Пример: curl http://localhost:5000/api/quizzes
